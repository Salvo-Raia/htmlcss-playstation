## 🎯 Assignment

Recreate the responsive layout of the PlayStation homepage, following the provided reference screenshots.

**The screenshots are the actual reference for this exercise, not the live website.**

The layout must be built using **Bootstrap 5**.

Keep the official Bootstrap documentation at hand to make proper use of the framework's main features. Helper classes and utilities may also come in handy.

You will have several days to complete the layout. As always, start by analyzing the main sections of the page.

Look for elements and sections that are identical or very similar, so they can be built once and reused, saving both time and code.

### 📒 Guidelines

- Since this is a responsive project, consider how each block and section will behave on different screen sizes from the very beginning.
- Keep your code organized, but don't over-optimize during the initial development of each block. You can always come back later to clean up, optimize and make adjustments.
- When planning reusable components, remember that this approach will save you time in the long run.
- Since this is a particularly long layout, focus on completing one section at a time, including its responsive behavior.
- Once a main section works correctly, move on to the next one.
- Choose the development order of the sections strategically, keeping optimization and code reuse in mind.

### 💡 Suggestions & Notes

Start simple and take things one step at a time.

Always try to understand what you're building and aim to complete the exercise, but don't rush to finish it at all costs if that means losing track of what you're doing.
